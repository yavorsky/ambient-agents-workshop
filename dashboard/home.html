Run sheet

Before (10 minutes)

  1. One terminal: cd ~/Development/yavorsky/ambient-agents-workshop && pnpm start. It starts everything clean. Leave it running.
  2. This page: everything under “Ready for the talk?” green.
  3. One Chrome window on the projector: /stage. A second window on your laptop: /presenter (it follows the slides). A tab with /dashboard: click Start sound once.
  4. Optional: code ~/Development/yavorsky/ambient-agents-workshop-wt/stage shows the code of the step on screen (it follows L). Live coding: pnpm wt claude stage in a second terminal; on a build slide paste the prompt before L, run it with pnpm wt start stage, and L replaces it with the tested step. If something breaks

  • The slide says “not running”, or numbers look stuck: press L again (about 3 s).
  • The chat errors or hangs: say “the model is slow today” and go on. No later slide needs that answer.
  • Gate reasons say “llm” or “rules” instead of “clef”: that is the fallback working. Keep going.
  • Everything is wrong: in the terminal Ctrl-C, pnpm start (about 20 s), back to the slide, L.
  • No sound: click Start sound in the dashboard tab itself (browsers need one real click there).
